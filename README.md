# Tikvex Downloader — GitHub Pages Website

A professional, responsive static website ready for GitHub Pages.

## Before publishing

1. Open `index.html`.
2. Replace both `https://uptodown.com/` links with your **actual Tikvex Uptodown app URL**.
3. Replace `support@tikvex.com` with your real support email in `index.html`, `privacy.html`, and `terms.html`.
4. If you have final screenshots, replace the mockup section in `index.html` with your images. The site works without them.
5. Review the privacy policy so it accurately describes the SDKs and data used by your Android app.

## GitHub Pages

Create a repository named `YOUR-USERNAME.github.io`, upload all files in this folder to the repository root, then enable:

**Settings → Pages → Deploy from a branch → main → / (root)**

Your site will be available at:

`https://YOUR-USERNAME.github.io/`
